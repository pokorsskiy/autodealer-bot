# Dealer Auto Web App

Демонстрационный Telegram Web App с каталогом автомобилей, калькулятором и
заявками менеджеру. В Telegram-чате остаются короткое стартовое сообщение и
одна кнопка открытия приложения.

## Возможности

- каталог из шести демонстрационных автомобилей с реальными фотографиями;
- поиск по марке и модели;
- фильтры по марке, цене, году, пробегу, кузову и приводу;
- сортировка по цене и году;
- избранное в рамках текущей сессии Web App;
- подробный экран автомобиля;
- заявка на выбранный автомобиль;
- отдельная форма обращения за помощью с выбором;
- предварительный калькулятор стоимости;
- FAQ и временные заглушки отзывов, общего чата и соцсетей;
- сохранение заявок в SQLite и уведомление менеджера в Telegram.

Данные автомобилей и цены используются только для демонстрации интерфейса.

## Настройка

Создайте локальный `.env` по образцу `.env.example`:

- `BOT_TOKEN` — токен отдельного showcase-бота;
- `YOUR_CHAT_ID` — Telegram ID менеджера, которому поступают заявки;
- `WEB_APP_URL` — публичный HTTPS-адрес содержимого папки `web/`;
- `DB_NAME` — необязательный путь к SQLite-файлу.

При первом запуске бот создаёт базу `showcase_webapp_leads.db`. Если существует
старая версия таблицы заявок, перед добавлением новых колонок автоматически
создаётся резервная копия с расширением `.bak`.

## Запуск и проверка

```powershell
python check_project.py
python -m unittest test_bot.py
python bot.py
```

Для локального просмотра статической части:

```powershell
python -m http.server 8000 --directory web
```

Для работы внутри Telegram папка `web/` должна быть опубликована по HTTPS, а
полученный адрес указан в `WEB_APP_URL`.

# Второй showcase: Telegram Web App

Бот открывает каталог и форму заявки внутри Telegram. Интерфейс лежит в папке `web/` и должен быть опубликован по HTTPS.

## Настройка

1. Создайте отдельного бота в BotFather.
2. Скопируйте `.env.example` в `.env`, заполните токен, chat ID и `WEB_APP_URL`.
3. Загрузите содержимое `web/` на статический HTTPS-хостинг.
4. Запустите бот: `python bot.py`.

Для локальной разработки Telegram не откроет обычный `http://localhost`; используйте HTTPS-туннель или тестовый HTTPS-хостинг.

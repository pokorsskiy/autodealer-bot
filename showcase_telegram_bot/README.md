# Первый showcase: Telegram-бот

Демонстрационный бот, где каталог, выбор автомобиля и заявка работают только через сообщения и кнопки Telegram.

## Запуск

1. Создайте отдельного бота через BotFather и скопируйте `.env.example` в `.env`.
2. Укажите `BOT_TOKEN` и `YOUR_CHAT_ID` в `.env`.
3. Проверьте конфигурацию: `python check_project.py`.
4. Запустите: `python bot.py`.

Заявки сохраняются только в `showcase_telegram_leads.db` внутри этой папки и пересылаются администратору.

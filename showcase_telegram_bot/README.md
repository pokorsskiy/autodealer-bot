# Telegram showcase

Каталог, выбор автомобиля и заявка работают в сообщениях и кнопках Telegram.

Заполните в локальном `.env` значения `BOT_TOKEN`, `YOUR_CHAT_ID` и при
необходимости `DB_NAME`, затем запустите:

```powershell
python bot.py
```

Заявки сохраняются в SQLite-базе внутри этой папки и пересылаются администратору.

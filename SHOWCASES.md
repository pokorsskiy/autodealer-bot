# Три демонстрационных сценария

| Папка | Сценарий | Токен | Web App |
| --- | --- | --- | --- |
| `showcase_telegram_bot` | Вся заявка и навигация в Telegram | отдельный | не нужен |
| `showcase_webapp_bot` | Каталог и форма только в Web App | отдельный | собственный HTTPS URL |
| `showcase_hybrid_bot` | Быстрые действия в Telegram + каталог в Web App | отдельный | можно использовать URL второго demo |

## Порядок запуска

1. В каждой папке скопируйте `.env.example` в `.env`.
2. Создайте по отдельному боту через BotFather и укажите его токен в соответствующем `.env`.
3. Для второго и третьего демо опубликуйте `showcase_webapp_bot/web/` по HTTPS и укажите URL.
4. В каждом каталоге запустите `python bot.py`.

Локальные `.env` и `*.db` уже исключены из Git. Не используйте токен основного бота в демонстрациях.
